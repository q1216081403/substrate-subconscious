## 这是什么

一个概念 Demo，用来证明一件事：

> **用现有的技术，就能把一个人的"潜意识判断模式"录下来，并生成成一段看得见的影像。**

产品分三步：

| 步骤 | 做什么 | 技术 |
|---|---|---|
| **01 观察你** | 摄像头看视线与表情，麦克风听语气与停顿 | 端侧视觉 + 声学模型 |
| **02 读懂你** | 从上万条数据里找出反复出现的判断模式 | 多模态大模型长序列推理 |
| **03 生成你的世界** | 把结论渲染成一段影像 | 文生视频模型 |

## 核心发现示例

Demo 内置了一份被观测 21 天的模拟画像。它最有意思的地方不是分数，是**隐喻**：

| 发现 | 隐喻 | 分数 | 说明 |
|---|---|---|---|
| 功利性视角 | **印钞机** | 82 | 社交场合中，人被无意识抽象为"功能接口"——情绪是噪音，资源是信号 |
| 尺度错位 | **蝼蚁** | 68 | 世界被感知为一张巨大的电路板，所有人都是微小节点，包括自己 |
| 消耗式节奏 | **吃饭机器** | 74 | 一天被切成若干"功能格"，每个格子都要被填满，而不是被体验 |
| 低温共情 | **隔着一层玻璃** | 41 | 能看见温度，却感受不到温度 |

每个发现都附带**证据链**（原始观测记录），让人能反驳——比让人只能接受更重要。

> **一句话总结**
> 你不是不敏感，你只是把敏感用在了**判断**上，而不是**感受**上。

## 技术实现

全链路均为当前已成熟技术，本 Demo 只演示可行性：

- **采集层** — 端侧视觉模型（人脸框、微表情）与声学模型（语速、音高、停顿）在本机运行，原始画面与声音不出设备
- **推理层** — 多模态大模型对齐多周行为序列，从"谁被注视多久"这类原始信号，推导到"功利性视角 82"这类人格结论
- **生成层** — 文生视频模型按分镜脚本渲染

**本仓库所有画面与视频均由 AI 生成，无实拍、无素材库。**

### 真正的门槛在哪

技术不是门槛——采集、推理、生成三环都已成熟。

门槛是 **心理学判读框架**：如何把行为序列翻译成人格，并且说出来让人信。

## 本地运行

**H5 版**（任意静态服务器）：

```bash
cd web
python -m http.server 8080
# 打开 http://127.0.0.1:8080
```

摄像头功能需要 HTTPS 或 localhost。

**小程序版**：微信开发者工具 → 导入项目 → 选择 `miniprogram` 目录 → AppID 选"测试号"。

## 部署

线上版部署在 **GitHub Pages**，来源分支 `gh-pages`：

| 分支 | 内容 | 用途 |
|---|---|---|
| `master` | 完整源码（含小程序工程、文档） | 开发、参考 |
| `gh-pages` | 仅 H5 部署产物 | 线上访问 |

修改内容后重新部署：

```bash
# 从 web/ 同步到 gh-pages
cp -r web/* ../_pages_build/ && cd ../_pages_build
git add -A && git commit -m "update" && git push origin gh-pages
# GitHub 自动重建，约 1 分钟生效
```

Pages 设置入口：仓库 → Settings → Pages → Source 选择 `gh-pages` 分支。

## 隐私立场

- 原始画面与声音**在本机处理，不上传**
- **看脸会得到一个人的隐私，看模式才得到一个人的自我认知**
- 我们产出的不是监控录像，是一份自我报告
- 分数必须配证据链——**让人能反驳，比让人只能接受重要**
