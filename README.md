# 心象宫殿 · Palace of Mind


> 同一个现实世界，在不同人的扭曲认知里，会变成完全不同的世界。
> 本工具把「行为信号 → 认知维度 → 心象世界」渲染成一段人人看得懂的 3D 隐喻短片。

**这不是读心术，也不是心理诊断。** 它采集的是*行为信号*（面部微表情、视线、语音语调、用词），
推断的是一组粗糙的心理学维度，最终把「某种价值观 / 欲望 / 认知偏差」用 P5 认知宫殿式的
视觉隐喻表现出来。观众看到的不是一个人的内心真相，而是**一种被夸张后的观看方式**。

---

## 快速开始

```bat
run.bat
```

或手动：

```bash
python -m http.server 8000
# 浏览器打开 http://127.0.0.1:8000/index.html
```

- 推荐 Chrome / Edge（语音识别用 Web Speech API，仅这两家支持中文连续识别）
- 摄像头可选：没有摄像头可以用「演示模式」手动调参，直接产出概念短片
- **本地运行**时依赖已本地化（`vendor/`），离线可用；**GitHub Pages 在线版**的人脸模型与 WASM 自动从 CDN 加载（仓库不含 18MB 二进制），视频/音频/转写依然全部在浏览器内处理，不上传任何服务器

## 使用流程

| 步骤 | 做什么 |
|---|---|
| 1 知情同意 | 阅读伦理条款：本地处理 / 仅限本人或已同意对象 / 隐喻非诊断 |
| 2 采集 | 摄像头 + 麦克风 + 中文语音转写；自然交谈 1–3 分钟效果最好 |
| 3 分析 | 十维信号 → 12 个心象世界匹配打分 → 注意力热区 / 价值关键词 |
| 4 宫殿 | 选择场景（自动匹配或手动），实时渲染，可录制带字幕的短片 |
| 5 导出 | WebM 视频 / JSON / HTML 报告 / AI 视频生成提示词 + 分镜 |

## 方法：从信号到宫殿

**采集层**（`js/capture.js`）
- 人脸 478 关键点 + 52 blendshapes（MediaPipe FaceLandmarker，本地 WASM）
- 视线：虹膜相对眼角位置 → 注视方向 / 注视镜头占比
- 语音：自相关基频检测（60–600Hz）、RMS 音量、频谱质心、语速（起音计数）、音高抖动
- 语言：Web Speech API 中文转写 → 价值词典统计

**推断层**（`js/signals.js`）——十个 0–1 维度：

| 维度 | 主要依据 |
|---|---|
| 唤醒度 | 音量 · 动作能量 · 音高波动 |
| 情绪基调 | 微笑/皱眉 · 平均音高 · 用词情感色彩 |
| 支配倾向 | 音量 · 语速 · 直视占比 · 眨眼抑制 |
| 紧张防御 | 眨眼率 · 眉压 · 音高抖动 · 口误率 |
| 人物化倾向 | 交易性词汇占比 · 情感平淡度 |
| 权力崇拜 | 等级/统治类词汇 · 支配倾向 |
| 猜疑多虑 | 动机揣测类词汇 · 视线回避 · 紧张 |
| 欲壑难填 | 索求类词汇 · 负性情绪 |
| 操纵布局 | 棋局/控制类词汇 · 支配倾向 |
| 评价焦虑 | 他人眼光类词汇 · 视线回避 |

**渲染层**（`js/palace/`）——每个场景 = 现实组 + 心象组，按时间轴交叉淡入：
- 场景参数由信号实时驱动：雾浓度=紧张、灯光色=唤醒/基调、镜头抖动=唤醒、视线热区=被照亮的区域
- 每个场景带 4 段旁白字幕，保证「大家一看就懂」

## 导出物

- **短片** `心象宫殿_<场景>.webm`——1280×720，含字幕、进度条、合成配乐（可选混入原声）
- **JSON**——全部维度、关键词、匹配依据、聚合指标
- **HTML 报告**——可直接打印/分享的自包含报告
- **AI 视频提示词**——把宫殿译成可灵 / 即梦 / Runway 等模型的 prompt（中英双语）+ 分镜脚本

## 伦理与局限（重要）

1. **不能读心。** 所有画面是行为信号的隐喻化再创作，置信度取决于采样时长与环境。
2. **同意原则。** 只采集本人或已充分知情同意的对象；严禁偷录偷拍。
3. **本地优先。** 视频/音频/转写全部在浏览器内处理，不上传任何服务器，可断网运行。
4. **不可用于决策。** 不得用于人事、司法、医疗、金融等高风险场景。
5. **文化偏差。** 关键词词典为简体中文语境，跨语言/方言场景需重新校准。

## 技术栈

- Three.js r160（本地 vendor）—— 程序化 3D 场景
- MediaPipe Tasks Vision（本地 WASM + 模型）—— 人脸关键点/混合形状
- Web Audio API —— 声学特征 + 氛围配乐合成
- Web Speech API —— 中文语音识别
- Canvas + MediaRecorder —— 字幕合成与视频导出
